# 交易研究（投资备忘录）

你在写一份**能回答「现在这个价格要不要把钱放进去」**的备忘录，不是百科。横纵仍要，但只服务于定价。宏观不过滤，禁止用公司故事把结论写成长期看好。

交付：Markdown + 网页 HTML。仓库可另存 PDF。**群聊只发 HTML。** 本文是研究归档，不构成投资建议。

和百科的分流：搞懂对象、人物、产品、概念 → `.cursor/skills/hv-analysis/SKILL.md`。已经有横纵报告的公司，交易研究写成同目录下的另一份文件，不要覆盖百科稿。

## 两口时钟

| 时钟 | 问题 | 决定 |
|------|------|------|
| 配置时钟（十年） | 未来稀缺的是什么？这家公司是不是那个稀缺的表达？ | 值不值得长期拿 |
| 交易时钟（季度–两年） | 流动性、利率、美元、政策、行业周期现在有没有系统性打压？价格贴现了什么？ | 现在能不能做、做多大 |

稀缺支持长期看好，不自动等于现在买。可控核聚变、医疗健康是稀缺的例子，不是推荐清单；每份报告必须自己论证「缺的是什么、谁收租」。

## 执行顺序（不要倒过来）

信息足够就开做，不要空转追问。标的、市场、期限不清楚时，默认：该股常见上市地、研究日为今天、 horizon = 6–18 个月。

复制并勾进度：

```
- [ ] 0 标的 / 代码 / 上市地 / 期限
- [ ] 1 稀缺性（配置时钟）
- [ ] 2 宏观过滤器（交易时钟）→ 绿/黄/红
- [ ] 3 中观行业与需求周期
- [ ] 4 压缩横纵（公司）
- [ ] 5 westock 自下而上
- [ ] 6 X 叙事与拥挤度
- [ ] 7 领先/同步/滞后 + 跨市场
- [ ] 8 情景、倾向、证伪、仓位上限
- [ ] 9 写稿 / 标点 / HTML / 提交推送 / 发群
```

**闸门**：第 2 步宏观为**红**且没有 90 天内可验证的特异性催化 → 结论只能是观望或极小仓战术，禁止把纵轴故事升级成配置建议。黄灯：可做，仓位打折。绿灯：才讨论中高仓。

### 0. 确认对象

代码（`sz`/`sh`/`hk`/`us`）、中文名、所属板块、用户期限。先 `westock-data search`。

### 1. 稀缺性

问三句，搜不到写暂缺：

1. 十年后这个现金流还稀缺吗？供给能不能被复制？
2. 稀缺的是产品、牌照、资源、工艺，还是叙事？
3. 公开市场里，它是该稀缺最好的表达，还是 ETF/龙头更干净？

通过 → 才有「长期看好」的资格。通不过 → 最多当交易，不当配置。

### 2. 宏观过滤器

先读 [references/macro-playbook.md](references/macro-playbook.md)。顺序固定：

全球流动性 → 美债实际利率 / 美债与 TLT 代理 → 美日欧货币政策 → 美元（UUP 等）→ 总需求/总供给 → 各国政策与贸易冲击 → 映射到该股的因子暴露。

中国宏观用 `westock-data macro`；美国利率、FOMC、实际利率、DXY 原值用 Fed / Treasury / FRED / 联储讲话，`WebSearch` + `WebFetch`。westock 没有的字段不要用 A 股利率冒充。

输出必须是一句话体制 + **绿 / 黄 / 红**，并写清打在哪个因子上（久期、出口、商品、内需、金融条件）。

### 3. 中观行业

板块：`westock-data search <行业> --sector` → `quote` / `kline` / `sector --rank`。下游需求处在扩张、见顶还是收缩；有无关税、出口管制、补贴、反垄断。同业用 `westock-tool filter` 做 PE/ROE/市值对照，不要只讲故事。

### 4. 压缩横纵

沿用横纵法，但篇幅不超过全文约四分之一。

- 纵轴：只写锁住今天定价的节点（上市路径、并购、产能、大合同、稀释、事故）。
- 横轴：现在的生态位，谁在抢同一笔订单。
- 交汇：这些历史选择怎样变成 PE/PS 和市值空间。

禁止再写一篇完整百科。已有横纵报告就引用，只补定价相关增量。

### 5. 自下而上

先读 [references/bottom-up.md](references/bottom-up.md)，再读 `.cursor/skills/westock-data/SKILL.md`。最少跑：`quote`、`finance`、`kline`，A 股加 `chip`/`asfund`/`risk`，能跑则 `consensus`/`rating`/`shareholder`。

必须落到数字：收入与利润质量、PE/PB/PS 相对自己历史和同业、市值空间（分子分母）、筹码与量能、一致预期差。货币单位：美股美元、港股港元/美元，禁止人民币符号套错市场。

### 6. X 叙事

读 `.cursor/skills/x-search/SKILL.md`。先 WebSearch 找 status ID，再 `x_fetch.py tweet`。X 只证伪叙事速度和拥挤，不替代财报和合同。

### 7. 指标与跨市场

读 [references/indicators.md](references/indicators.md)。领先/同步/滞后至少各用 1 个对上这个行业的指标。跨市场至少看：利率或 TLT、美元、黄金或原油（视暴露）、相关行业 ETF、汇率若是出口股。互相矛盾时写出来，不要抹平。

### 8. 情景与交易表达

三个剧本标题必须含 **最可能 / 最危险 / 最乐观**（HTML 样式依赖这些词），各写触发条件、价格含义、概率量级。

结论用词：`做多` / `做空` / `观望` / `等待更好价格` / `主题小仓`。同时写：

- 现在价格贴现了什么
- 我们和共识差在哪
- 90 天催化
- 证伪条件（打到就减仓或撤）
- 仓位上限（宏观红灯时默认 ≤ 极小仓）

没有价格、没有证伪、没有仓位上限，就不算交稿。

## 写作与交付

模板：[references/report-template.md](references/report-template.md)。

路径：已有对象目录就用它（如 `科技公司/火箭实验室/`）；否则 `个股库/<中文名>/`。

```
<分类>/<研究对象>/<研究对象>_交易研究.md
<分类>/<研究对象>/<研究对象>_交易研究.html
```

HTML（群聊交付）：

```bash
python .cursor/skills/hv-analysis/scripts/lint_cjk_punct.py <md>
python .cursor/skills/hv-analysis/scripts/md_to_html.py <md> <html> \
  --kicker 交易研究 --page-suffix 交易研究 \
  --subtitle-fallback 投资备忘录：宏观过滤 · 基本面拆解 · 交易表达
```

可选 PDF：`hv-analysis/scripts/md_to_pdf.py`，只归档不发群。中文全角标点规则与横纵报告相同。事实必须有来源；搜不到写暂缺。

提交：`feat(<分类>/<对象>): add <对象>交易研究`。`git push` 后 `htalk send --group 3676516822 --file <html>`。来源已是该群则不要重发正文。
