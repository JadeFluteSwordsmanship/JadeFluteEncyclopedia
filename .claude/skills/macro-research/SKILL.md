# 宏观研究（时点报告）

写一份**钉在具体时间节点上的板块判断**，不是公司百科，也不是单票备忘录。消费、地产、出口、流动性、政策脉冲都属于这里。

交付：Markdown + 网页 HTML。仓库可另存 PDF。**群聊只发 HTML。** 研究归档，不构成投资建议。

## 目录（强制）

```
宏观研究/<板块或概念>/<时间节点>/<板块>_<时间节点>_宏观研究.md
宏观研究/<板块或概念>/<时间节点>/<板块>_<时间节点>_宏观研究.html
```

- **板块或概念**：消费、地产、出口、汽车、白酒、流动性……用市场通用中文名。
- **时间节点**：`YYYYQn`（季度，如 `2026Q3`）或 `YYYYMM`（月度，如 `202610`）。同一板块不同时点是**不同子目录**，不要覆盖旧稿。
- 不要把文件丢在 `宏观研究/` 根目录。不要为公司另开这里；公司仍在 `个股库/` 或已有对象目录。

## 和另外两套的分流

| 问题 | 走 |
|------|----|
| 这个时点消费/地产能不能配、宏观在干什么 | 本 skill |
| 这一只股票现在这个价格买不买 | `trade-research` |
| 这是谁、怎么长成这样 | `hv-analysis` |

用户丢来一篇宏观公众号/研报并要求写报告时，用本 skill：**先核数字，再决定同不同意原文**，禁止扩写成原文复述。

## 执行顺序

```
- [ ] 0 板块 / 时间节点 / 触发（数据、政策或文章）
- [ ] 1 一手数据核对（统计局、央行、财政部、Fed；westock 宏观与板块行情）
- [ ] 2 宏观过滤器（流动性 → 美债实际利率 → 美日欧政策 → 美元 → 总需求总供给 → 国内政策）
- [ ] 3 领先 / 同步 / 滞后 + 跨市场
- [ ] 4 板块拆解（谁在拉、谁在拖；价格是否已贴现）
- [ ] 5 与触发文章/共识的分歧
- [ ] 6 三个剧本、证伪、仓位含义
- [ ] 7 写稿 / 标点 / HTML / 提交推送 / 发群
```

宏观过滤器细节见 `trade-research/references/macro-playbook.md` 和 `indicators.md`。中国数用 `westock-data macro`；美国利率、FOMC、DXY 用 Fed / FRED / Treasury。westock 没有的字段不要用 A 股利率冒充。

闸门打在**这个板块的因子**上，绿/黄/红。红灯时禁止把一个月的边际改善写成配置拐点。

## 写作

模板：[references/report-template.md](references/report-template.md)。中文全角标点，定稿跑 `hv-analysis/scripts/lint_cjk_punct.py`。三个剧本标题必须含 **最可能 / 最危险 / 最乐观**。

HTML：

```bash
python3 .cursor/skills/hv-analysis/scripts/md_to_html.py <md> <html> \
  --kicker 宏观研究 --page-suffix 宏观研究 \
  --subtitle-fallback 时点研究：板块 · 宏观 · 交易含义
```

可选 PDF：`hv-analysis/scripts/md_to_pdf.py`，只归档不发群。

提交：`feat(宏观研究/<板块>/<时间节点>): add <板块>宏观研究`。`git push` 后 `htalk send --group 3676516822 --file <html>`。
