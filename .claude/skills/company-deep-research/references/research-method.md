# 六问研究方法与证据闭环

## 研究问题先于数据

回答“这家公司如何赚到钱、竞争变化怎样影响钱、价格已期待多少钱，以及下一步什么证据会改变判断”。每节至少包含一条具体判断、支撑事实、因果机制、最强反例和下一验证方式。用数据支撑叙事，不用数据清单代替叙事。

深度来自拆开关键机制。例如订阅转型：合同经济价值可能改善，但收入确认后移、云成本上升、现金回收变化、客户使用量变化可以同时发生。必须分别研究，不能把营收下降一律说成需求变差，也不能靠一个 ACV 增长抹掉毛利恶化。

## 第一问：行业驱动与供需平衡

1. 定义可计价的产品／服务；按客户实际支付的钱拆市场，分清硬件、软件、服务和资产交易。相邻市场不能随意合并，TAM 不等于公司可服务市场，更不等于收入。
2. 对最近驱动按证据硬度排列：已执行法规／订单与预算／资本开支与产能／领先统计／管理层观点／第三方预测。排序是定性时明确标注，不伪装成量化排名。
3. 建立供需表：品类、买方及预算、有效需求与指标、供给及竞争者、产能／交付约束、价格／毛利、库存／订单、当前平衡、未来增量、来源周期。
4. 商品行业尽量写物量平衡：期初库存＋产量＋进口－出口－消费＝期末库存，统一地域、周期和单位；缺数据不能编出精确缺口。
5. 软件／服务没有吨位平衡时写经济平衡：客户预算、渗透、席位／使用量、付费意愿、交付／人才能力、替代成本。明确“预算约束”“能力瓶颈”“同质供给”而非假装存在可观测物量。
6. 写驱动如何传到公司数量、价格、份额、成本或现金，并找至少一个同样重要的限制因素。

交付供需表后给一句判断：缺的到底是什么、哪一层收租、公司是否拥有瓶颈、供需变化是否能落在现金流。

## 第二问：商业模式拆解

按分部／产品／客户／地域拆，区分现金牛、增长引擎、期权业务与边缘业务。每个主要分部回答：

- 为谁解决什么问题，客户不买会怎样，谁做采购决策。
- 计费单位、量价公式、一次性／订阅／用量／首付里程碑／佣金模式。
- 交付义务、收入确认时点、回款、合同负债／应收与坏账。
- 直接成本、毛利、获客与研发、规模效应、资本开支和营运资本。
- 单位经济的稳定性、客户队列、留存与扩容、增长上限。

收入可写客户数×客单价、销量×单价、交易量×佣金率等，只在对应模式有意义时使用。ARR、ACV、RPO、backlog、GMV 不互换，也不直接加到收入。增长至少拆量、价、份额、结构／会计、并购、汇率；提出最关键的两至三个变量，成对列出增长机制与脆弱点。

## 第三问：行业地位、竞争格局与颠覆

先选真的争夺同一订单／预算的对手。客户、供应商、生态伙伴与竞对分列；上游大厂或相邻技术公司不自动是可比公司。

同业表至少有业务重合、规模、增长、盈利质量、关键运营指标、估值与可比性说明。上市同业带市场和标准代码，未上市同业标明身份，不强行计算 PE。没有可靠市占率就用可验证的收入、装机、客户覆盖等代理指标，并承认不能据此证明市场第一。

按业务层／技术代际研究颠覆：

| 分析层 | 必问 |
| --- | --- |
| 功能与产品 | 新技术是替代还是提高原产品价值？同任务的质量／成本如何？ |
| 工作流与分发 | 谁拥有客户入口、集成、迁移成本、渠道？ |
| 数据与验证 | 数据可复制吗？是否有可核实的闭环、审计／合规优势？ |
| 商业化与计费 | 价值单位从席位变用量、设备变服务等时，谁获得定价权？ |
| 交付与资本 | 研发领先能否转换为交付和现金，是否被资本密集玩家压制？ |

为每个护城河给“优势证据／侵蚀机制／领先警报”。不把品牌形容词写成壁垒，不把技术榜单排名直接当商业优势。给最有力的空头／反向解释并做回应，不能用无关小风险陪衬多头故事。

## 第四问：股价隐含预期、估值与非共识

先读 `valuation-and-financials.md`。分别说明：公司质量、当前价格、隐含预期，三者不等同。用至少一种可复算的逆向定价，回答当前价格要求怎样的增长、利润率、成功率或现金流；再与行业容量和公司能力约束比。

非共识卡必须包含：市场观点的出处与日期、自己的差异、支持与反证、为何影响盈利／倍数、验证指标和预计窗口。如果没有分析师覆盖或可靠一致预期，写“尚无可核实共识；本节为待验证假设”。公开新闻已广泛讨论的主题不自动是非共识；没人提也不自动是市场没有定价。

写三情景：输入、业务机制、估值方法、企业价值到股权价值桥、隐含每股区间（如适用）、触发与失效。不是给单一目标价；不必硬给无依据概率。至少对最敏感的两个参数做敏感性说明，计算可用本地可复算脚本或宿主计算工具，但不能靠文字心算。

## 第五问：财务质量与风险

盈利、现金、资产负债、股东稀释四条线一起看。财务年报尽量五至十年，季度八至十二季；短历史明确实际窗口。读 `valuation-and-financials.md` 的利润—现金桥和适用性。

风险表写：风险、机制、影响变量、领先信号、验证材料、时间窗口、可恢复／永久损失。不强造量化概率。短期是财报与订单验证；中期是商业模式迁移与竞争；长期是需求替代、治理与资本配置。

压力测试集中在致命变量：现金烧损、债务到期、融资稀释、价格／毛利、关键客户或监管。把经营风险与证券定价风险分开；财务暂时安全不等于估值安全。

## 第六问：四状态与后续验证

四状态是解释框架，不是互斥的四象限或总和一百的概率。分别写历史已发生、当前主导与未来切换：

| 状态 | 必要证据 | 常见误判 |
| --- | --- | --- |
| 盈利兑现 | 核心盈利／FCF按预期增长，关键运营改善已进报表，质量与持续性可核实 | 一次性收益、调整后口径转正、营收增长替代核心盈利 |
| 逆境反转 | 先证明真实困境与底部，再证明导致困境的变量反转并传导到经营 | 股票跌过就是困境；主动会计转型就是逆境；单季反弹就是反转 |
| 估值压缩 | 同口径倍数下降或价格所要求的回报提高，盈利预期、风险溢价变化可解释 | 仅凭股价回撤；忽略每股稀释与分母变化 |
| 预期提高 | 指引／盈利预测修订、业务验证或同口径倍数反映预期上移 | 涨价自动等于共识上修；未经验证的概念等于真实改善 |

选择一个主要解释，允许一至两个次要／风险状态；如果不能选择，指出缺失的观测而非平铺四个标签。每种状态给明确否定证据。

跟踪清单按重要性排列：指标／当前基准／下一观测窗口／支持主判断的条件／使判断失效的条件／来源。财报日期区分官方确认与预计；阈值必须由历史、经营目标或模型边界推导，不能随手编“低于百分之几就失败”。

最终形成最可能、最危险、最乐观三个未来路径，写从一个状态迁移到另一个状态所需证据。结论只给研究倾向和待验证命题，不转成下单、仓位与止损指令。

## 第七问（仅按用户明确要求追加）：非个性化立场与证伪退出

默认六问独立完成，不自动开启交易附录。用户明确要求七问或追加第七问时，仅在q6后追加q7，使用本技能的方法与标准库生成器，不把trade-research作为运行必需。

1. 先写分析者前提：研究周期、信息／行情时点、无杠杆示例、非用户仓位与非个性化立场。未知用户期限时使用明确标注的分析者假设，不推测用户资金、持仓或风险偏好。
2. 在long／short／观望中选择条件化立场，说明哪些经营与定价机制使其成立；证据不够或可执行性存疑时观望，不强造买卖结论。
3. 至少列出核心证据的原文出处、来源编号和时点，主动检验最强反证并给出处或明确缺口；把事实、研究者测算与假设分开。
4. 分别写论点证伪、价格风险止损、时间止损和止盈。证伪对应经营／估值假设失效；价格风险阈值须由波动、流动性、估值或可核验价格结构推导，保留基准时点与币种；时间止损对应明确窗口内未兑现的催化／验证；止盈对应估值兑现、催化完成或反向证据。不要把固定5–8%盲套为所有标的止损，也不把价格止损等同于论点证伪。数据不足不造价格，明确无法设价与补证条件；观望给升级／放弃条件，不适用项说明原因。
5. 区分short的研究倾向与可执行做空。A股融券能否实际借到不能从融券余额推断；另核验券源、账户资格、成本、期限与召回风险，未核验标注不可确认执行。说明跳空、流动性与止损不保证成交；无杠杆示例不消除做空潜在无上限损失。
6. 不给用户仓位、杠杆、账户或下单指令，保留完整免责声明。draft仍不做价格判断或交易结论；若用户要求第七问但资料不足，q7仅列前提缺口与待核验事项，不把骨架当作立场已成立。

## 停止条件

六问已覆盖；关键定价变量有证据或明确缺口；已检查强反证；关键财务／估值可复算；继续搜索不再改变判断。缺资料时缩小结论和明确不确定性，不能用漂亮 HTML 掩盖不完整。
