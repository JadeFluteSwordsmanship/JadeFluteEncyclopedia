## 安装 weasyprint（quant 环境）— 踩坑记录
- 必须 `conda install -n quant --override-channels -c https://conda.anaconda.org/conda-forge weasyprint`（走代理）。
- 用户 .condarc 指向清华镜像 `mirrors.tuna.tsinghua.edu.cn`，该域名在 gfwlist 内属直连，当前网络连不上 → 必须 `--override-channels` 强制用官方 conda-forge 源 + 代理。
- 代理仅在单次命令临时设置：`$env:HTTP_PROXY/HTTPS_PROXY="http://192.168.68.68:8888"`，`NO_PROXY="127.0.0.1,::1,localhost,10.*,192.168.*"`。
- **关键坑**：直接用 `D:\ProgramData\anaconda3\envs\quant\python.exe -c` 跑会报 `cannot load library libgobject-2.0-0`（error 0x7e），因为未激活环境、PATH 缺 `Library\bin`，原生库依赖链加载失败。必须用 `conda run -n quant python ...` 才会正确注入 PATH。
- `markdown` 不在 quant，已用 `conda run -n quant pip install markdown`（3.10.3）。
- 最终验证：`conda run -n quant python -c "import weasyprint, markdown"` → weasyprint 69.0 | markdown 3.10.3 ✅。
- 注意：conda 安装输出会被 CodeBuddy 的 `[safe-delete]` 包装干扰，报错被吞；用 `> log 2>&1` 写文件 + read_file 才能看到真实错误。
