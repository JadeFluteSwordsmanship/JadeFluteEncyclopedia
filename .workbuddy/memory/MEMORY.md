# MEMORY.md - 长期记忆

## 项目背景

这是一个**投资百科全书**式的 Knowledge Base，组织结构按"行业 → 产业链分层 → 子环节 → 标的"。

## 项目约定

### 目录组织
核心规则：**一个研究对象一个目录**。该对象的 md / pdf / html / 图片 / 数据全部放进 `<分类>/<研究对象>/`，不要散落在分类根目录。

- `人物/` — 如 `人物/李宗盛/`、`人物/孙中山/`
- `游戏/` — 如 `游戏/金铲铲之战/`、`游戏/暗区突围/`
- `科技公司/` — 如 `科技公司/谷歌/`、`科技公司/苹果/`
- `个股库/` — 如 `个股库/江波龙/`、`个股库/中际旭创/`
- `金融行业/`、`国际政治/`、`生物与医学/` — 同样按对象建子目录
- `AI全行业/` — AI 基础设施/模型/应用三层。叶节点空文件是产业链占位符，保持为空文件，不要改成目录
- `人形机器人/` — 上游零部件/中游 OEM/下游应用/具身智能。叶节点空文件同样是占位符，不要改成目录

### 文件命名规范
- 横纵报告：`<对象名>_横纵分析报告.md` / `.pdf`，放在该对象目录内
- 个股笔记：`<代码><公司名>.md`，如 `个股库/中际旭创/300308中际旭创.md`
- 板块总览：该层的 `README.md`
- 主题分拆：`0X_主题名.md`（带数字前缀排序），放在该主题目录内

### 个股 md 内容规范
已有格式参考 `300475香农芯创.md`、`301308江波龙.md`：
- 顶部可带研报摘录（时间、机构、评级）
- 或采用结构化分析（板块标签、业绩、看点、风险、跟踪清单）
